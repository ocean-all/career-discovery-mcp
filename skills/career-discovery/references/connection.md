# Connection

Use the `career_discovery` stdio MCP server. Its `get_status` returns the project root. The installer writes `local-installation.json` beside this reference for fallback CLI usage; this generated local file is not distributed.

The tools include get_search_profile, save_search_profile, build_search_plan, get_status, get_google_search_links, list_jobs, read_daily_summary, run_collection and open_naver_discovery. Google links default to the last 30 days and are a discovery aid, not a live-search API. Naver result content stays in the user's viewer. See the checkout's docs/MCP.md for setup. No installation step starts the daily scheduler.
