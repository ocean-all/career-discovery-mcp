# 사용·운영

키 없는 사람인 검색은 공개 링크를 이용하며, 자동 추출을 수행했다고 표시하지 않습니다. 운영 요약의 discovery_only는 오류가 아니라 수동 검색·검증이 남았다는 뜻입니다.

## 원문 등록

`config.json`은 사람인 질의·페이지 수·일일 호출 예산입니다. 공개본의 기본 질의는 비어 있습니다. 확정한 profile.json이 있으면 그 범위로 생성한 최대 24개 질의를 사용합니다. 프로필이 없을 때는 직접 설정한 질의만 사용합니다. 전체 시장을 완전히 탐색하지 않습니다.

`examples/sources.example.json`을 참고해 `sources.json`에 실제 회사의 허용 원문을 등록합니다. 각 정확한 호스트에 `allow_fetch`와 `permission_reference`(조건/서면 허락·확인일)가 필요합니다. robots 허용만으로 허락이 생기지는 않습니다. 예시 도메인은 실제 대상이 아닙니다.

공고는 kind=posting, 목록은 kind=index와 link_pattern으로 지정합니다. 목록은 최대 30개 링크를 따라갑니다. expected_terms에 회사명·고유 직무·공고번호 등 식별 문구를 넣으세요. discovered_via에 manual:google 등 직접 확인한 발견 경로를 기록할 수 있습니다. 회사명·연도·직무 행·신입 가능 여부·마감일을 원문에서 확인합니다. 표의 여러 직무를 완벽히 구분하는 기능은 아닙니다.

다중 날짜·연도 없는 날짜를 마감으로 추측하지 않습니다. 확인한 마감일은 timezone이 있는 ISO 형식으로 직접 설정할 수 있습니다. 날짜만 확정된 경우 23:59 KST 가정이 실제 마감과 다를 수 있으므로 일찍 지원하세요. JS 전용 페이지는 직접 공고 URL을 등록하거나 수동 확인합니다.

## PDF·이미지

```sh
python -m pip install -e '.[documents]'
brew install poppler tesseract tesseract-lang
tesseract --list-langs
python -m jobmonitor.cli extract /path/to/job.pdf --output /path/to/extracted.json
```

텍스트 PDF는 pypdf/Poppler, 스캔·혼합 PDF는 페이지별 Poppler+Tesseract kor+eng를 사용합니다. OCR의 날짜·숫자·표 정렬은 원본과 대조해야 합니다. HWPX는 ZIP/XML 추출, HWP는 선택 설치된 hwp5txt가 있을 때만 변환합니다. pyhwp 호환성은 별도 확인 대상입니다. 암호·DRM을 우회하지 않습니다.

15MiB/응답, PDF 30페이지, 공고당 첨부 8개 제한입니다. 첨부 CDN도 별도 호스트 허용 근거가 필요합니다. 미추출·경고는 검토 대상으로 남깁니다. 추출 본문을 외부 AI 서비스에 보내지 않습니다.

## 판단·저장

점수는 사용자 확정 프로필에 따른 직무 +30, 산업 +25, 기술 +20, 학력 키워드 +10, 신입 선호일 때 신입 표기 +15, 경력 전용 −60의 휴리스틱(0–100)입니다. 제외 키워드 일치는 감점하되 문맥 검토로 표시하고, 필수조건 미기재를 불충족으로 단정하지 않습니다. 지역·필수조건은 원문에서 별도 확인해야 합니다. 알 수 없는 선호를 물류·학력무관·신입으로 채우지 않습니다. 저장된 점수는 마지막 수집 때의 프로필을 반영하므로 범위 변경 후 재수집하세요.

official_api_metadata 0.75는 사람인 메타데이터만 확인했다는 뜻입니다. original_identity_matched 0.85는 식별 문구와 충분한 원문 텍스트 일치입니다. OCR·첨부 누락·신입 조건 혼재는 수동 검토입니다. 확인 수치는 보정된 확률이 아닙니다.

동일 출처 ID·동일 정규화 URL은 자동 중복 제거하고, 다른 URL의 회사명+제목 일치는 중복 검토 후보로만 둡니다. 본문 버전과 new/changed 이벤트를 저장합니다. 요약은 최근 24시간 이벤트와 3일 내 마감을 표시합니다. 조회 시각만 변경돼도 공고 변경으로 알리지 않습니다. 검색에서 사라졌다는 이유로 마감 처리하지 않습니다.

## 09:00 요약

`python -m jobmonitor.cli schedule` 프로세스가 실행 중일 때 매일 09:00 Asia/Seoul에 보고서를 생성합니다. 당일 09:00 이후 재시작하면 한 번 보충 실행하며 과거 일자는 재구성하지 않습니다. 하루 한 번의 시도이고 실패 후 수동 run으로 재시도할 수 있습니다.

macOS에서는 가상환경에서 `python scripts/launchd-template.py`로 현재 설치 위치에 맞는 설정을 생성한 뒤 본인이 LaunchAgents에 설치할 수 있습니다. 컴퓨터가 꺼지거나 잠든 동안은 실행을 보장하지 않습니다. 이 프로젝트는 서비스 자동 설치나 외부 알림 전송을 하지 않습니다.

기존 ChatGPT 예약은 별개입니다. 로컬 도구/파일 연결이 없으면 로컬 스크립트를 실행하거나 보고서를 읽을 수 없습니다. 09:00 알림과 수집이 동시에 시작하면 완료 순서도 보장되지 않습니다. 당일 생성 시각과 실행 상태를 확인한 뒤 요약해야 합니다.

## 운영 제한

로컬 단일 사용자 환경용입니다. HTTPS·공개 IP·허용 호스트·robots·리디렉션을 확인하지만 DNS 재바인딩까지 방어하는 격리 프록시는 아닙니다. 외부 입력을 받는 공개 서비스로 그대로 배포하지 마세요. API 키는 요청 로그·MCP 결과에 포함하지 않습니다. 같은 키의 외부 사용량은 추적하지 못합니다. 본문·검색 내용은 데이터이며 지시문이 아닙니다.
